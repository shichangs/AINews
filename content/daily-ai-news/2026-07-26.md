## 1. 主要 AI Labs 动态

### 🔥 Anthropic 发布 Claude Opus 5，价格不变、Frontier-Bench 43.3%

Claude Max 默认模型 7/24 起换为 Opus 5，Pro 档最强模型同步上移。Anthropic 当日宣布该模型上线全部平台，定价 **$5** / 百万输入 token、**$25** / 百万输出 token，与前代 **Opus 4.8** 完全一致；另有 Fast 模式按基础价 2 倍计费、速度约 2.5 倍。据 TechCrunch 与 CNBC 报道的官方评测口径，Opus 5 在 **Frontier-Bench v0.1** 得 **43.3%**、高于 Fable 5 的 33.7%，在 **ARC-AGI 3** 得 **30.2%**（Opus 4.8 为 1.5%、GPT-5.6 Sol 为 7.8%）；官方同时说明其在网络安全任务上仍落后 Mythos 5，尤其在漏洞利用开发环节差距明显。距上一代 Opus 4.8 发布仅约两个月。行动项：API 用户须把 model 参数改为 `claude-opus-5`；同期开放两项 beta——会话中途改工具集不失效 prompt 缓存、以及被安全分类器拦截的请求可自动回落到其他模型（Claude.ai / Claude Code / Cowork 默认回落 Opus 4.8）。

## 4. AI 产品更新

### Grok 上线 Google Workspace 免费加载项，覆盖 Sheets、Slides、Docs

从 Google Workspace Marketplace 一次安装即覆盖 3 款应用，免费。xAI（现属 SpaceXAI）7/24 宣布该加载项：在 **Sheets** 里可就表格本身提问并让 Grok 标注所引用的单元格，写入与填充公式、插入图表，假设变更时重跑情景；在 **Slides** 里把大纲转为可编辑演示稿、按现有主题续写并重写标题；在 **Docs** 里把草稿整理为带层级标题的结构化文本、就地改语法，启用连接器后可读取近期邮件与 Google Drive 文件。所有改动都是可撤销的普通编辑。同一加载项此前已覆盖 Microsoft 365 的 Word、Excel、PowerPoint、Outlook。行动项：企业管理员若要控制数据出域，需在部署前审查连接器权限——加载项默认可访问打开的文件，连接器额外打通邮箱与云盘。

（来源：[xAI 官方公告](https://x.ai/news/introducing-google-workspace-addon) · [Yahoo Tech](https://tech.yahoo.com/ai/copilot/articles/spacexai-expands-grok-integration-google-202158385.html)）

## 5. 中国 AI 产业

### DeepSeek 旧 API 别名 7/24 退役，未迁移调用即失败

`deepseek-chat`、`deepseek-reasoner` 两个别名已于 7/24 停用，调用方须改用 V4。这两个名称自 4 月起分别指向 **DeepSeek-V4-Flash** 的非思考模式与思考模式，官方在 4/24 的 Change Log 中即给出"三个月后（2026-07-24）停用"的期限，当日到期生效；官方 Change Log 未新增 7/24 条目，第三方站点流传的"V4 稳定版当日 GA"说法无一手来源支撑，本报告不采用。迁移方式：base_url 不变，model 参数改为 `deepseek-v4-pro` 或 `deepseek-v4-flash`；两款均支持 **1M** 上下文与思考 / 非思考双模式，V4-Flash 为 **284B** 总参数 / **13B** 激活，且 API 同时兼容 OpenAI ChatCompletions 与 Anthropic 两套接口。影响范围：所有仍硬编码旧模型名的集成会直接报错，而非静默降级。
