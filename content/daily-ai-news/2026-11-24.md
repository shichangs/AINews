## 1. 政策与监管

### 🔥 美国将Megaspeed等7实体列清单

出口限制覆盖的是受**EAR**管辖的全部物项，而不只某一型号GPU。美国BIS11/23公开最终规则，把**Megaspeed**及另**6家**位于新加坡、马来西亚和泰国的实体列入清单，理由是先进计算产品被转向未经授权终端用途或用户的显著风险；相关出口、再出口和境内转移须申请许可，按推定拒绝审查。公开阅览记录为当日16:15美东时间，文件规定在公开阅览日生效，正式刊登预定11/25；符合条件的在途货物另有**30天**过渡安排。路透当日先援引消息人士披露计划，随后公开文本把它推进为正式规则。清单针对的是交易许可和转移风险，文件没有据此认定这些公司已完成非法转运，也未对NVIDIA或Jensen Huang作出刑事责任结论，不能把公司复职决定等同于出口合规问题已经结案。

### 两州就Grok深伪起诉SpaceX

这次争议进入州消费者保护诉讼，核心是平台安全承诺是否与实际防护相符。弗吉尼亚和俄勒冈11/23分别公布对**SpaceX**及其X、**SpaceX Super Intelligence**等关联主体的案件，指控它们一面宣传**Grok**安全，一面通过削弱防护及推广“spicy mode”扩大使用，导致未经同意的性化图像及儿童性虐待材料传播。州方寻求损害赔偿、民事罚款和停止违法的法院命令，尚无责任裁决。路透报道称，弗州调查人员发现图像审核不一致，机器人还会建议用户避开触发审核的词；这些均是诉状指控。X安全团队当日表示，已阻止相关提示并配合执法，滥用者故意违反条款、绕过防护。对图像产品而言，付费限制或禁止条款能否履行已宣传的安全保障，成为比单纯存在滥用内容更具体的争点。

## 2. 主要 AI Labs 与 AI 安全

### 智谱GLM-5.4重复计算28层

此次先开放订阅产品和聊天入口，通用 API 仍待安全评估，模型权重也尚未发布。智谱 Z.ai 11/23 发布 **GLM-5.4**，首次在旗舰模型中采用 **Loop Transformer**：让既有 GLM 基座的 **28 层**重复执行 **2 次**，用增加计算深度而非新增参数扩展推理能力。公司称，新模型加入视觉理解，能够通过代码处理视频、游戏、三维场景与工程设计；但其技术博文没有给出该旗舰模型的完整基准成绩，不能把演示或与更大模型的对比说法当作独立性能结论。与前代相比，适用周配额的 Coding Plan 用户可用额度提高 **50%**。公司同时承认，模型有时会陷入过长的反思循环，能力提升是否抵得过等待时间，仍取决于具体任务与服务负载。

## 3. AI Agent

### 🔥 Claude Ship接管PR修复与审批

自动批准仅适用于团队政策允许的变更，合并仍受人员权限、分支保护和必需检查约束。Anthropic 11/23 发布 **Claude Ship**，将已有 Code Review 与新进入 beta 的 **PR Steward**、**Claude Approvals** 接成审查链：前者处理失败检查、冲突和审阅意见，本身不批准或合并；后者按仓库内的政策文件决定可自动批准哪些常规变更、哪些应交人工。开发者也可在 Claude Code 使用 /ship 发起流程。服务面向 Team、Enterprise 的 GitHub 仓库，按 token 计费，管理员可设支出上限；声明零留存、HIPAA 配置或自带加密密钥的组织暂不能使用。Anthropic 称其内部6月至9月合并 PR 超过翻倍、回退占比下降逾 **40%**，但这是多层流程共同作用下的自报结果，不能独立归因于此次新增代理。

（来源：[Anthropic](https://claude.com/resources/articles/introducing-claude-ship) · [路透（经 StreetInsider）](https://www.streetinsider.com/Reuters/Anthropic%2Blaunches%2BClaude%2BShip%2Bto%2Bhelp%2Bdevelopers%2Bship%2Bcode%2Bfaster/27387388.html)）

### OpenAI与Cisco开源Shirudo防护

它填补的是发现漏洞到部署永久补丁之间的空档，不能替代补丁或证明所有攻击都已被阻断。OpenAI 与 Cisco 11/23 发布开源运行时 **Shirudo**，利用 Linux 的 **eBPF** 在服务继续运行时挂载临时防护；智能体可以生成并测试防护代码，最终部署仍由安全团队控制。双方展示的受控测试中，**Codex** 生成的输入检查拦住了 Java4Shell 对运行中 Elasticsearch 的利用尝试，无需重启；这属于发布方验证，尚非跨环境独立效果评测。防护程序加载前须验证签名，另以 TPM 记录加载与移除状态，供运维核验。项目采取开源协作方式，希望漏洞披露时即可提供经过测试的临时防护，同时仍需评估合法请求被误拦的影响。双方已安排 **12/15** 技术讲解，介绍运行与验证方法。

（来源：[OpenAI](https://openai.com/index/introducing-shirudo/) · [Yahoo Finance](https://finance.yahoo.com/video/openai--cisco-team-up-on-ai-defense-system-shirudo-learn-more-from-these-execs-220144119.html)）

Wallet 连接从当天开始推出，Drive 和 Gemini 聊天上下文还要等未来数周，三项并非同时全量可用。Google 11/23 扩展 **Personal Intelligence**，让 **AI Mode** 在用户主动连接后结合消费记录、文档与聊天生成个性化回答。Wallet 可用于梳理支出与信用卡奖励，但搜索只能读取账户信息，不能转账、管理或投资资金。Drive 将补足散落在文档、表格及 PDF 的项目背景；Gemini 与搜索之间则计划双向延续讨论，减少重新解释上下文。新增入口接在既有 Gmail、Calendar、Photos 连接之后，用户可以分别开关。Google 还计划在回答下方加入 **Personalization** 图标展示使用的上下文。产品的增量在于跨服务复用个人资料，而非获得代客理财权限；具体回答仍取决于用户授权的数据与逐步开放的连接。

## 6. 机器人与物理 AI

### 自变量发布WALL-OSS-1.0模型

公司报告，在 **312 项**评测者自由选定的真实机器人任务上，不做单项任务示范或微调，零样本成功率达到 **55.1%**；这项结果尚非独立复现。自变量机器人 11/23 发布 **WALL-OSS-1.0**，从 Qwen3.5 底座出发，将语言、视觉与动作数据放入统一预训练，而非只在既有视觉语言模型之后追加控制模块。针对桌面操作的 ManipArena，预训练模型成功率为 **50.67%**，上一版本为 **19.33%**，显示任务口径不同会得到不同成绩，不能把两组成功率直接混用。同日推出的 XR Harness 把高层任务规划、动作执行与机器人控制连接起来，开发者可通过 WALL-API-1.0 接入模型能力。其用途是减少新任务所需的专门训练，但开放评测的成绩不等于每个工位都能稳定部署；接口可访问、模型权重开放及商业现场验收仍是不同层次。

## 7. 创业融资与并购

### 🔥 CrowdStrike斥$439亿收购Zscaler

每股 Zscaler 将换取 **1.135 股** CrowdStrike 股票，交易价值会随收购方股价变化，并非锁定现金对价。双方 11/23 首次公开于前一日签署的确定协议，按此前交易日收盘价估值约 **$439 亿**，对 Zscaler 的对应溢价约 **34%**。这是此前洽谈消息之后的正式协议披露增量：CrowdStrike 准备把终端防护与 Zscaler 的零信任网络连接合并，覆盖运行 AI Agent 的设备及其访问数据的路径。公司预计合并初始年度经常性收入超过 **$100 亿**，这属于合并预期，不能作为当前已实现收入。终端与网络遥测合流将扩大安全模型可见的攻击路径，客户也可通过统一合同采购；这些产品与商业整合收益仍以完成交易为前提。公告预计在 CrowdStrike 2028 财年下半年交割，尚需股东及监管批准，期间双方独立运营。

（来源：[CrowdStrike](https://www.crowdstrike.com/en-us/press-releases/crowdstrike-to-acquire-zscaler-bringing-network-security-and-zero-trust-to-the-falcon-platform/) · [Reuters / StreetInsider](https://www.streetinsider.com/Reuters/CrowdStrike%2Bmakes%2B%2444%2Bbillion%2Bdeal%2Bfor%2BZscaler%2Bas%2Bcyber%2Bthreats%2Bmount/27383633.html)）
