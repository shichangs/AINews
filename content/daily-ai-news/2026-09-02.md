## 1. 政策与监管

### 🔥 美方在 G20 推「卡罗来纳原则」，要求签署国不为 AI 新设监管机构

签署国须承诺"把新监管留给真正新颖的问题"，会议 9/1 在北卡 Chapel Hill 开幕。这份文本由白宫科技政策办公室主任 **Michael Kratsios** 与商务部长 **Howard Lutnick** 主导，美国今年轮值 G20 主席国；除承诺不新设 AI 监管机构外，还要求投资"加速发现的基础研究"并为新技术拓宽商业化通道。Kratsios 给出的理由是，决策者不必把每项新兴技术都当成前所未见的政策问题。

出席者包括 **Elon Musk**、英伟达 **黄仁勋** 与 OpenAI **Sam Altman**。对照面是欧盟：AI Act 第 50 条透明度义务 **8/2** 已生效，欧委会 8/31 刚按 DSA 把 ChatGPT 认定为超大型在线搜索引擎（详见 09-01 归档 §1）。下一可核验节点是签署国名单——文本本身不具约束力，签了几家、有没有欧盟成员国，决定它是宣示还是规则。

### 韩国 2027 年预算 821 万亿韩元，半导体基础设施单列 21.3 万亿

财源是三星与 SK 海力士的 HBM 利润，支出增幅 **12.8%** 为韩国史上最大。韩国政府 9/1 公布 2027 年总支出 **821 万亿韩元**（约 **$5,970 亿**），把 AI 与半导体列为核心。**21.3 万亿韩元** 投向工业用水、电网与物流等芯片制造配套；**2.6 万亿韩元** 投向物理 AI 示范项目；另为一个国家级基础模型供应 **1 万张** GPU。

结构上这是把制造业优势转成本土 AI 生态的一次财政押注——韩国此前的角色集中在高带宽存储与先进封装的供给侧，模型与应用层薄弱。下一节点是国会审议：预算案须在年底前通过，规模与科目均可能被削。

## 2. 主要 AI Labs 动态

### 🔥 Anthropic 发布 Claude Fable 5.1 与 Mythos 5.1

缓存读取降至 **$0.25/百万** token，典型负载成本较 Fable 5 降约 **25%**、重度 agent 负载降约 **45%**。输入输出单价不变，仍为 $10/$50 每百万 token。**Fable 5.1** 9/1 在 AWS、Google Cloud 与 Azure 同步可用，API 模型名 `claude-fable-5-1`。

基准侧的口径按 Anthropic 自测：Terminal-Bench-Science 0.1 为 **52.6%**（Fable 5 复现 24.7%、Opus 5 复现 29.0%，官方标注标准误 ±3.5–4.5 分）；Terminal-Bench 4.0 为 **55.8%**，放宽网安防护的 **Mythos 5.1** 同题为 **60.9%**；Humanity's Last Exam 无工具 60.9%。两个模型是同一底座、防护档位不同，Mythos 5.1 只对通过网安与生命科学两个认证项目的机构开放。

科学侧给了三个可外部复核的样本：Mythos 5.1 设计的蛋白结合体在 12 个靶点上命中率近 **50%**（该领域常见水平 10–15%），其中 3 个靶点的亲和力较 Adaptyv Bio 竞赛最佳投稿高 10 倍；Fable 5.1 用 30 多年前 Magellan 雷达数据训练网络，把金星三分之一表面的高程图分辨率从 10–20 km 提到 2–3 km，已按 CC 协议在 Zenodo 发布；Mythos 5.1 改写 GPU kernel，把七个开源基因组模型推理提速最高 **2.5 倍**。防护侧：Claude Code 用户的网安拦截次数平均降约 **60%**，Fable 5.1 起允许用于识别软件漏洞但不允许开发利用代码；新建 API 账号不再能编辑 Claude 既往思维链，用于封堵一条公开的蒸馏路径。下一节点是 Mythos 5.1 的访问范围——目前仅限美国机构，扩至境外须与美国政府协调。

### 🔥 Anthropic 与 Lambda 签 $350 亿云算力协议，英伟达持有场地租约

该园区目标 **2027 年 Q1** 首次通电，合同约 **350 MW**、六年期，英伟达同时是租约持有方与芯片供应方。据 WSJ 8/31 首发、Reuters 与 Bloomberg 9/1 跟进：**Anthropic** 向英伟达投资的"neocloud" **Lambda** 采购算力，机位在比特币矿商 **Hut 8** 于得州 Nueces 郡开发的 Beacon Point 园区，占地 525 英亩、临近 Corpus Christi。Anthropic 拒绝置评，英伟达、Lambda、Hut 8 未即时回应。

### Anthropic 撤回 30 天数据保留，改由客户自存日志

企业客户可把监控日志存进自有云账户、由自己人工审核，Anthropic 侧不再保留 **30 天**。9/1 公布的 **Enterprise Frontier Safeguards**（EFS）把检测与存储拆开：自动化系统仍分析滚动窗口内的流量，找攻击性网安、生物能力开发与凭据泄露的信号，但命中后的标记直接交给客户，由客户自己的团队处置。

30 天保留是随 Fable 5 引入的，动因是跨会话、跨账号的攻击无法靠单次交互判断，代价是金融、医疗等受监管行业客户难以使用。EFS 与逾 **100 家** 客户共同设计，参与方包括系统性风险分析与韧性中心（ARC，成员含高盛、摩根士丹利、花旗、美银、富国的 CISO），以及 Comcast、KPMG、万事达、Salesforce、Visa。支持面覆盖 Claude Code、Claude Enterprise、Claude Platform、Amazon Bedrock、Google Agent Platform 与 Microsoft Foundry；Anthropic 不为 EFS 收费，客户自存产生的存储与流量费由云厂商计。下一节点是分阶段推出，目标今秋广泛可用；在此之前合资格客户对 Fable 5 与 5.1 直接适用零数据保留。

## 3. 医疗 AI

### 临床医生可在 ChatGPT 里读 Epic 病历并检索 9 个公共医疗数据源

接口为只读——不能写病历、不能下医嘱、不能改临床文书。**OpenAI** 9/1 宣布医疗机构可把自有 **Epic** 环境接入 ChatGPT for Healthcare，医生可跨就诊记录、化验结果、用药与专科文书提问；同日上线的 Healthcare Public Data 插件把 **9 个** 官方公共数据源做成连接器，含 ClinicalTrials.gov、CMS Coverage、RxNorm、DailyMed 与 PubMed。

限定条件有两层：一是面向机构而非个人账号，须由医院系统或临床团队部署；二是当前只对美国合资格的 ChatGPT for Clinicians 用户开放。只读设计把风险面压在"检索与问答"，把责任留在医生侧，这也是 EHR 厂商此前对生成式模型接入的主要顾虑。下一可核验节点是这两项功能是否扩展到 Epic 之外的 EHR 厂商。

## 4. 中国 AI 产业

### 华为上半年研发投入 1,213.8 亿元，占营收 25.9%

净利润同比降 **36%** 至 **238.1 亿元**，营收却涨 **9.6%** 至 4,678.2 亿元——差额被研发与成本吃掉。**华为** 8/31 披露半年报，研发支出同比 **+25.2%** 至 1,213.8 亿元，投向 AI、通信技术、智能终端与智能汽车解决方案；产品成本同比 +12.4%，快于营收增速，管理费用亦大幅上升。

Bloomberg 把利润下滑主要归因于存储涨价（memory crunch）——这与长鑫、SK 海力士的 HBM 产能主线是同一条供需曲线。用近四分之一的营收换自主供应链，是华为在美国出口管制下的既定选择，短期代价直接体现在利润表。下一检验点是全年报，通常在次年 3 月发布。

### 智谱上半年 API 收入占比升至 86.5%，去年同期为 15.2%

开放平台与 API 收入同比增约 **27 倍** 至 **8.25 亿元**，一年之内从边缘业务变成主收入源。**智谱**（现品牌 Z.AI）8/31 公告：截至 6/30 的六个月总收入 **9.54 亿元**，同比 **+399.7%**；毛利 **2.52 亿元**，同比 +163.7%。

值得注意的是毛利增速（+163.7%）远低于营收增速（+399.7%），说明这轮增长仍以低毛利的 token 调用换规模。中国大模型 API 价格战持续，同场竞争者包括阿里、字节、月之暗面与 MiniMax。下一可核验节点是三季报或年报里 API 毛利率是否回升——若不回升，收入结构的改善不等于盈利路径成立。
