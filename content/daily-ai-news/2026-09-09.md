## 1. 主要 AI Labs 动态

### 🔥 千禧年难题第二次被解，OpenAI 与 NYU 数学家就优先权公开对立

七大千禧年难题中第二个被宣布解决，代价是一场关于优先权的公开对立。**OpenAI** 9/8 发布《On the Navier–Stokes Millennium Prize Problem》，称一个未公开的内部模型驱动的多 agent 系统证明三维不可压 Navier-Stokes 方程在光滑受力下可于有限时间形成奇点，并同时给出 Lean 形式化。据其披露，解出 Navier-Stokes 的那一组约 **1 万** 个并发 agent 运行 88 小时，Lean 验证再花 17 小时由 GPT-6 Astra 完成；跨全部尝试的问题共发出 **490 万** 条消息、约 **3,000 亿** 输出 token。公司明确表示不打算申领这项奖金。

争议来自时间线。NYU 的 **Tristan Buckmaster** 9/7 深夜发表声明并挂出三篇预印本——IPM 方程、二维 Boussinesq 系统、三维不可压 Euler 方程的光滑受力有限时间 blowup，均附 Lean 形式化——合作者是 **Anthropic** 研究员 **Levent Alpöge**，两人 8/15 得到首个 blowup 解、8/22 完成 Lean 验证。Buckmaster 称 OpenAI 在 9/6 的通话中提出两个方案，其中一个要求他单独署名并承认 OpenAI 模型解出全题，理由是不接受 Alpöge 的 Anthropic 任职；他引述对方在其拒绝后说"Why would you ruin your career?"。

OpenAI 数学家 **Sébastien Bubeck** 在 9/8 记者会否认取用对方材料，称"无论研究员还是 agent，在昨晚公开前都没有看到他们的工作"，并承认 OpenAI 是在 9/1 听到传闻后才集中攻这道题。两条独立线索指向同一个方法源头：Diego Córdoba 与 Luis Martínez-Zoroa 的"受力分层"构造。下一可核验节点是克雷数学研究所——其官网截至 9/8 仍将 Navier-Stokes 列为未解，受理与否是这项结果能否成立的外部检验。

### 🔥 高通拿下 AWS 定制推理芯片订单，认股权证挂钩 $600 亿采购上限

高通数据中心收入将在 **2026 年 12 月** 季度开始确认，芯片已投产。**AWS** 9/8 与 **高通** 签署多代定制 AI 推理芯片与 1.6T 光互连联合开发协议；据高通同日提交的 8-K，亚马逊关联方获得最多 **2,500 万股** QCOM 认股权证，行权价 **$161.26**、2036 年 9 月 3 日到期，其中 375 万股（15%）随首批采购承诺立即归属，其余按下单与实际采购分批归属，**$600 亿** 是十年期采购上限而非承诺收入。当日 QCOM 盘中最高涨 9.5% 至 $183.49，亚马逊跌约 1%，博通涨约 3%。

## 3. AI Agent

### 🔥 Meta 上线个人 Agent「Muse」，代下单的代价是邮箱、日历与支付授权

换取代办能力的代价是邮箱、日历与支付授权，超量后月费 **$20** 或 **$100**。**Meta** 9/8 在美国推出个人 AI agent **Muse**，由 Muse Spark 模型驱动，可发邮件、订行程、填表、把菜谱视频转成购物清单并完成下单，结账走 Link by Stripe，Shop Pay 与 1Password 集成随后上线。入口覆盖 Web、iOS、Android 与 WhatsApp，AI 眼镜稍后支持；免费档起步但需绑卡，付费档为 Power $20/月与 Maximum $100/月。连接器逐个授权，无 API 的服务由 Muse 通过浏览器访问。

Meta 称 Muse 跑在专属的 Muse Secure VM 内，独立浏览器、看不到用户密码与支付方式，另有一个 Sentinel agent 同机但系统级隔离运行，对话与数据不进入广告系统。这些说法尚未经第三方安全复核。语境是信任赤字：8/26 Meta 刚就 29 州提起的未成年人保护诉讼达成 **$180 亿** 和解。检验点是配套技术文档能否经外部安全研究者验证。

（来源：[TechCrunch](https://techcrunch.com/2026/09/08/meta-debuts-its-muse-ai-agent-will-consumers-trust-it/) · [Meta（Muse 安全与安全性说明）](https://research.meta.ai/blog/security-and-safety-for-ai-agents-our-approach-with-muse)）

## 4. AI 产品更新

### ChatGPT Images 2.5 上线，API 拆成 Flare 与 Sunburst 两档

生成延迟较 Images 2.0 最多降 **50%**，全订阅档位用户 9/8 起可用。**OpenAI** 当日发布 **ChatGPT Images 2.5**，官方口径是每周跨 ChatGPT Images 与 API 端 GPT-Image 模型生成超 **30 亿** 张图。新增能力集中在可控性：Sketch 允许直接在 ChatGPT 里手绘作为构图参考，模板覆盖海报、周边等常见版式，可在图上打点评论做局部修改，也可连同 prompt 一起分享。

API 端拆成两款：**GPT-Image-2.5 Flare** 为默认档，官方称画质高于 GPT-Image-2 且延迟低 50%；**GPT-Image-2.5 Sunburst** 面向精度优先、生成更慢的场景。Adobe Firefly、Manus、Higgsfield 为首批接入方，Manus 评测口径称 Flare 速度为 GPT-Image-2 的 2–4 倍。安全侧沿用 C2PA 元数据与隐形水印，系统卡已同步发布。

## 6. 医疗 AI

### AlphaGenome Atlas 开放 90 亿个单碱基变异的预计算影响

**1 PB** 预计算数据集免费开放学术使用，体量为 AlphaFold 结构库的 30 倍以上。**Google DeepMind** 9/8 上线 **AlphaGenome Atlas**，覆盖人类基因组中全部 **90 亿** 种单核苷酸变异——即每一个可能的单字母改变——预测其对基因表达与调控活性的影响，通过免费网页门户提供给学术研究者。

配套推出 AlphaGenome Variant Impact（AVI）评分，团队称其在临床基因组数据库上可把致病突变与无害改变区分开。局限同样明确：模型一次看 100 万碱基对的上下文，超出这一视野的远距增强子不在预测范围内；而许多疾病由多个变异共同决定，单点预测不足以定论。下一可核验节点是 AVI 评分能否在独立临床队列上复现区分能力。

（来源：[Google DeepMind](https://deepmind.google/blog/alphagenome-atlas-a-predictive-map-of-every-possible-dna-letter-change-in-the-human-genome/) · [Nature](https://www.nature.com/articles/d41586-026-02835-4) · [Fortune](https://fortune.com/2026/09/08/google-deepmind-ai-predictions-9-billion-mutation-human-genome/)）
