### 🔥 H200 首批进入中国，单家授权上限 10 万颗

### OpenAI 预览 Private Safety Processing，9 月起推送

零数据留存（ZDR）客户 **9 月** 起将收到跨会话风险监控，技术白皮书同月发布。OpenAI **8/19** 公告说明了这套机制解决的矛盾：现有 ZDR 兼容的安全系统逐次独立评估每次交互，而长任务智能体的风险往往只在多次交互的关联中才显形。新机制下客户内容或留在客户自控的基础设施，或存放在 OpenAI 侧、用客户掌握的密钥加密；自动系统只回传告警的类别与严重程度，OpenAI 人员不接触内容本身。例外仍是法定的儿童性虐待材料（CSAM）图像，会保留人工复核。参与共同设计的客户包括 Glean、Databricks、Abridge 与 Microsoft。目前处于早期客户测试阶段，ZDR 合同客户需要在 9 月推送前确认内容存放位置的选项。

（来源：[OpenAI](https://openai.com/index/offering-zero-data-retention-for-frontier-models/)）

## 3. AI Agent 与开发者工具

### Cursor 云端 Agent 可订阅事件源，自动跟进 PR 到完成

云端 Agent 现在能订阅 PR 与 Slack 线程，自行修 CI、回应机器人评论直到任务完成。Cursor **8/19** 的 changelog 把这组能力称为 Subscriptions，目前仅对云端 agent 开放：agent 订阅一个事件源，事件发生时被唤醒；它创建的 PR 会自动订阅并推进到底。同批更新还有三项：子代理可各自跑在独立虚拟机上，每个拿到项目的干净副本与独立上下文；`/goal` 给出长期目标、agent 持续做到完成；任何 skill 可用 ⌥⏎ 固定为 Custom Mode 常驻会话。方向与 Warp **8/18** 推出的 Factories 一致（封闭测试，合格企业获 **$10,000** 免费额度）——都在把一次性对话变成常驻流水线。Subscriptions 下放到本地 agent 的时间表，官方未给。

（来源：[Cursor Changelog](https://cursor.com/changelog/08-19-26) · [TechCrunch](https://techcrunch.com/2026/08/18/warps-new-system-is-an-out-of-the-box-software-factory-for-ai-development/)）

### Grok 4.6 上线 Amazon Bedrock，20 万 token 以上价格翻倍

AWS 全部支持区域即日可调 **Grok 4.6**，20 万提示 token 是价格分水岭。xAI **8/19** 宣布该模型进入 Bedrock：20 万 token 以下按 **$2 / $0.50 / $6**（输入 / 缓存输入 / 输出，每百万 token）计费，以上翻倍至 **$4 / $1 / $12**。模型规格为 **500k** 上下文窗口、四档推理力度（low / medium / high / xhigh），定位是长跑型智能体与交互式视觉任务。这是该模型在 8/12 Cursor 首发、8/14 打通 GitHub Copilot 全部 8 个入口（详见 08-16 归档）之后的第三个第三方分发面，也是 SpaceX 完成收购 Anysphere 后 Grok 首次进入 AWS 目录。跨云分发的下一个观察点是 Bedrock 侧的区域与配额扩展节奏。

（来源：[xAI](https://x.ai/news/grok-4-6-amazon-bedrock) · [AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-bedrock-grok-4-6/)）

## 6. AI 安全

### Copilot 一键漏洞细节公开，内存投毒可跨改密码存活

被投毒的 Copilot 长期记忆能挺过改密码、注销会话与设备重新注册，需人工清理。Varonis Threat Labs **8/19** 公开了 CVE-2026-24301（代号 CoSnitch）的细节：微软 **8/18** 修复该漏洞，距收到报告已近 **8 个月**。攻击链由三个弱点串成——`?q=` 参数配合一个未公开参数让攻击者的提示在页面加载时立即执行；被注入的提示可查询受害者已连接的 Gmail、Drive、日历或 OneDrive，把结果编码进 URL 后经 Copilot 自带的取链能力外传到攻击者的 webhook；被 Copilot 摘要的恶意网页还能把指令写进永久记忆。研究者未发现修复前有在野利用。行动项：管理员应确认租户已收到更新，并复查 Copilot 的连接应用授权与记忆存储。

（来源：[Varonis](https://www.varonis.com/blog/cosnitch) · [The Hacker News](https://thehackernews.com/2026/08/microsoft-copilot-personal-flaws-could.html)）
