### 🔥 据 FT：H200 首批进入中国，字节与腾讯各约 1 万颗

多数获许可的 H200 须留在香港，而字节、腾讯在港找不到可容纳的部署空间。Financial Times **8/19** 报道，两家公司过去数周各接收约 **1 万颗**，是北京放开进口后的首批到货，其他中国科技公司可能很快拿到同等规模的批次。许可结构分两层：美方此前已向约 **10 家** 中国公司发出出口许可、单家累计上限 **10 万颗**，中方则仍按单审批。H200 属上一代数据中心 GPU，中国客户仍无法购买英伟达最新代产品，因此这批到货只是缓解、不是解除算力约束。下一个可核验节点是 **8/26** 英伟达 Q2 FY27 财报——中国区收入指引是否随出货恢复口径。

### OpenAI 预览 Private Safety Processing，9 月起推送

零数据留存（ZDR）合同客户须在 **9 月** 推送前选定内容存放位置：自控设施，或 OpenAI 侧、由客户掌握密钥加密。OpenAI **8/19** 公告说明了这套机制要解决的矛盾——现有 ZDR 兼容的安全系统逐次独立评估每一次交互，而长任务智能体的风险往往只在多次交互的关联中才显形。新机制下，自动系统只回传告警的类别与严重程度，OpenAI 人员不接触内容本身；例外是法定须报告的儿童性虐待材料（CSAM）图像，仍保留人工复核。参与共同设计的客户包括 Glean、Databricks、Abridge 与 Microsoft。技术白皮书与推送同在 9 月，目前处于早期客户测试阶段。

（来源：[OpenAI](https://openai.com/index/offering-zero-data-retention-for-frontier-models/)）

## 4. AI Agent 与开发者工具

### Cursor 云端 Agent 可订阅事件源，自动跟进 PR

Cursor 云端 agent 可订阅 PR 与 Slack 事件被动唤醒，本地 agent 暂不支持。**8/19** 的 changelog 把这组能力称为 Subscriptions：agent 订阅一个事件源，事件发生时醒来，它自己创建的 PR 会被自动订阅并推进到底——修 CI、回应机器人评论直到完成。同批另有三项更新：子代理可各自跑在独立虚拟机上，每个拿到项目的干净副本与独立上下文；`/goal` 用来给出长期目标，agent 持续做到完成；任何 skill 都能用 ⌥⏎ 固定为 Custom Mode 常驻会话。方向与 **Warp** 8/18 推出的 Factories 一致（封闭测试，合格企业获 **$10,000** 一次性额度）——两家都在把一次性对话改造成常驻流水线，下放到本地环境的节奏是同一个观察点。

（来源：[Cursor Changelog](https://cursor.com/changelog/08-19-26) · [TechCrunch](https://techcrunch.com/2026/08/18/warps-new-system-is-an-out-of-the-box-software-factory-for-ai-development/)）

### Grok 4.6 上线 Bedrock，20 万 token 以上价翻倍

AWS 全部支持区域即日可调 **Grok 4.6**，20 万提示 token 是价格分水岭。xAI **8/19** 宣布该模型进入 Amazon Bedrock，官方公告给出的基础价是每百万 token **$2** 输入、**$6** 输出；据 AWS 侧文档，超过 20 万提示 token 后翻倍至 $4 / $12，缓存输入分别为 $0.50 与 $1。模型规格为 **500k** 上下文窗口与四档推理力度（low / medium / high / xhigh），定位是长跑型智能体与交互式视觉任务。这是该模型继 8/12 在 Cursor 首发、8/14 打通 GitHub Copilot 全部 8 个入口（详见 08-16 归档）之后的第三个第三方分发面，也是 SpaceX 完成收购 Anysphere 后 Grok 首次进入 AWS 目录。

（来源：[xAI](https://x.ai/news/grok-4-6-amazon-bedrock) · [AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-bedrock-grok-4-6/)）

## 7. AI 基础设施

### 欧洲新建 AI 数据中心平均距枢纽 175 公里

欧洲 2026–2028 年规划的超大规模园区平均距枢纽城市 **175 公里**，为历史均值的 **3.8 倍**。Reuters **8/19** 报道了 JLL 的这组测算：2022–2025 年已交付的同类园区均值为 **46 公里**，而绿地项目在 2026–2028 年管线中的占比由 **8%** 升到 **39%**。选址决策的第一顺位已从靠近人口与连接节点，换成可得电力、地价与并网速度。受益的是瑞典北部、西班牙与葡萄牙乡村等电力经济性更好的地区；伦敦、法兰克福、阿姆斯特丹、巴黎与都柏林仍占存量机房多数，但电网与土地约束在收紧。同日 CNBC 报道英伟达在北欧为持有 GPU 配额的企业与有地有电的运营商牵线，是同一约束的另一面。下一个可核验节点是这批 2026–2028 项目的并网时间表。
