## 3. AI 产品更新

### OpenAI 发布 GPT-Live 工程复盘，WARP 协议进入 IETF 流程

OpenAI 的 **WARP** 协议把 WebRTC 建连从 **6 次**往返压到 **1 次**，已提交 IETF。8/3 的这份工程复盘拆解第三代语音系统：模型全双工、听说同时进行，音频路径不再有 turn detector；深度推理异步委托给 GPT-5.5 等模型、不打断对话。媒体前端从 Python asyncio 重写为 Go 后，帧投递平滑度的 **p95 达到旧系统的 p50**；WARP 含 4 项向后兼容改造，配合 Instant Connect，客户端发**单个 UDP 包**即可开始会话。libwebrtc 与 Pion 已合入支持，受益的将是整个 WebRTC 生态的建连延迟。下一节点：GPT-Live API 开放，文中确认在准备中。

（来源：[OpenAI](https://openai.com/index/continuous-voice-interaction-with-gpt-live/)）

### Cursor 上线 Google Workspace 插件

Cursor 8/3 上线 **6 个** Google Workspace 插件，agent 直连 Gmail 与日历。清单为 Google Drive、Gmail、Calendar、Docs、Sheets 与 Chat，覆盖搜索云盘、收发邮件、建日程找空闲、读写文档表格、向 Chat 发消息，即日可在 Cursor Marketplace 或客户端 Customize 页安装。这一步与 §2 的千问办公同日落在同一场景——编码 agent 与办公 agent 的边界在数据接入侧消融。落地检验点在权限侧：6 个插件均需 Google OAuth 授权，企业管理员的行动项是放行前在 Google Admin 控制台限定这批插件的 OAuth scope。

（来源：[Cursor Changelog](https://cursor.com/changelog/google-workspace-plugins)）

### 据 TestingCatalog：微软全双工语音模型 MAI-Realtime 在测

微软被曝在测全双工语音模型 **MAI-Realtime**，双语音、**17 种**语言，可调用网页搜索。据 TestingCatalog 8/2 独家，该模型以隐藏早期入口出现在 MAI Playground，仅限一小批合作方测试：提供 Victoria 与 Grant 两个语音、会话中可自动切换语言，其试用观感是"比 MAI Voice 2 自然得多"。微软未公告该模型，也未发布模型卡、定价与上线区域。这在 MAI-Transcribe-1（听）、MAI-Voice（说）之外补上全双工一块；加上 §3.1 的 GPT-Live 与 xAI 8/5 的 grok-voice 别名切换，三家全双工语音在同一个月进入交付节奏。可观测节点：MAI Playground 是否把该隐藏入口转为公开列表。
