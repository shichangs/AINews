### 🔥 Gemini 3.7 Flash 上线，引入价为上代一半

引入价仅持续到 **2026 年底**，之后恢复原价，按用量锁定预算的团队需要在此前完成迁移测算。Google **8/13** 发布 **Gemini 3.7 Flash**，距 3.6 Flash 仅三周。编码侧 DeepSWE v1.1 由 49.0% 升至 **65.3%**，FrontierCode 1.1 Main 由 34.4% 升至 43.6%；WebDev Arena 的 Elo 由 1538 升至 1588。知识密集场景上，处理复杂文档的 GDP.pdf 基准由 22.0% 升至 34.0%，衡量真实业务流程的 AutomationBench 由 17.0% 升至 **30.4%**。渠道上，Gemini app 内当日只向 Spark 推送（需 AI Pro 或 Ultra 订阅），同时在 Google Antigravity、AI Studio、Android Studio 与 Gemini Enterprise 可用。安全侧更新了针对 CBRN 与网络攻击滥用的防护。

### OpenAI 预览 Ultrafast 档，GPT‑5.6 Sol 输出提至 750 token/秒

限量预览只对选定客户开放，扩容节奏未给日期，其余团队目前只能登记等候。OpenAI **8/13** 在 API 侧推出该服务档：**GPT‑5.6 Sol** 的输出速度最高为标准档的 **14 倍**，每秒最多 **750** 个输出 token，算力由 **Cerebras** 提供。定位是把前沿模型放进对延迟敏感的环节——公司列出的场景包括故障排查、金融研究与风控、实时语音客服、结账前的商品答疑，以及把过夜批量实验压缩成日内可迭代的交互式研究。OpenAI 内部已把它用于事故响应与研究检索。早期客户包括 Jane Street、Podium、Basis 与 Rogo。

（来源：[OpenAI 官方公告](https://openai.com/index/previewing-ultrafast/)）

### 🔥 DeepSeek V4-Pro-0813 转正，Harness 以 MIT 开源，API 8/16 涨价

API 新价 **8/16 16:00 UTC** 生效，缓存命中价涨约 **6 倍**，反复读同一批文件的 agent 工作流受冲击最大。DeepSeek **8/13** 把 deepseek-v4-pro 端点切到 **V4-Pro-0813** 构建，模型名、参数量与 100 万 token 上下文不变，官方称既有集成无须改动，并新增对 OpenAI Responses API 与 Codex 集成的原生支持，推理强度可设 low / high / max 三档。厂商自测口径下，Terminal Bench 2.1 由 72.1 升至 **87.9**、DeepSWE 由 12.8 升至 **62.7**；第三方 Artificial Analysis 的智能指数由 45 升至 53，与 GLM-5.2 并列，仍落后 Kimi K3 的 60 与 Claude Opus 5 的 63，新构建的权重尚未公开。同日发布的 **Harness v0.1** 开发者预览以 MIT 协议开源，建在新发布的 Cordis 插件系统上，模型、工具、沙箱、会话与界面均为可替换插件，会话日志可续跑、分叉与回放；项目负责人是 3 月自 Jane Street 加入的崔天翼。定价改为峰谷两档，高峰时段为 UTC 1:00–4:00 与 6:00–10:00：非高峰 V4-Pro 输入由 $0.435 升至 $0.66、输出由 $0.87 升至 $1.98，高峰时段翻倍至 $1.32 与 $3.96；缓存命中由 $0.003625 升至 $0.022（非高峰）与 $0.044（高峰），缓存折扣从约 1/120 收窄到 1/30。
