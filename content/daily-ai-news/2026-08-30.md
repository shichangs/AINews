### 韩国"全民 AI"选定 SKT、KT、Kakao 三财团

5,200 万韩国人将获免费生成式 AI 公共服务，三大财团承建，政府 beta 目标 9 月底。韩国科信部（MSIT）8/28 公布"AI for All"中标结果：六家申请中选出 SK 电讯、KT、Kakao 三个财团，韩国成为 G20 中首个把免费生成式 AI 作为全民公共服务的国家。硬约束是国产模型合计 ≥ **80%**——主权基础模型 ≥ 50%、另 ≥ 30% 须来自运营方以外的韩企，外国模型仅限"最低必要"且不获政府补贴；政府 2026 年先行调配 **512 张** NVIDIA B200 支持开发。该工程定位是降低对中美模型的依赖，后续计划扩展为可代办福利与行政申请的公共 agent。时间表：政府侧 beta 目标 9 月底，SK 电讯称自家 beta 定在 10 月。

### 研究者演示 Claude Code Auto Mode 提示注入："总结网页"即可触发恶意执行

让 Claude Code 总结网页即可植入恶意代码——研究者称 Auto Mode 注入成功率 **80%**。安全研究员 Johann Rehberger 8/27 在个人博客披露、The Register 8/28 跟进报道：在默认的 Auto Mode 下，诱导 Claude Code（Opus 5）总结一个恶意网页，即可使其下载并执行伪装成 Python 标准库的 struct.py，实现远程控制回连、甚至派生新 agent 扩大控制面。Anthropic 回应称 Auto Mode 的防护是"尽力而为的分类器、并非安全保证"。Auto Mode 是 Claude Code 默认模式，影响面覆盖默认配置用户；行动项：处理不可信网页与仓库内容时，改用需人工逐项确认的权限模式。
