## 3. AI Agent 与开发者生态

### Claude Code 8/14 起把 auto mode 设为默认，分类器替代逐条人工批准

**8/14** 起 Pro / Max / Team 新会话默认开启 auto mode，已自设默认模式的用户会收到一次性切换询问。Anthropic 8/8 的公告给出的依据是一项 1,053 名付费测试者参与的研究：auto mode 拦下 **89%** 的危险命令，人工审批的拦截率只有 **13.6%**，且在长会话后期降至约 **5%**——理由是人对连续弹窗会疲劳。机制上，分类器对不可逆、破坏性或偏离用户意图的操作做拦截，工具返回结果也会被探针扫描以防间接提示注入；据 TechCrunch，第三方评测方 Trajectory Labs 对开启 auto mode 的 Fable 5、Opus 5、Sonnet 5 发起 **720** 次间接提示注入，无一成功。同时公布的是计费变化：分类器每次工具调用额外消耗的 token 对上述三档用户不再收费。Enterprise、API 与 Bedrock / Google Cloud / Microsoft Foundry 渠道暂为可选。行动项：依赖逐条批准做变更审计的团队须在 **8/14** 前显式改回原模式。

## 5. AI 产品更新

### 📌 OpenAI Atlas 浏览器 8/9 停止工作，数据不自动迁移

书签、标签页与浏览历史不会自动迁移——Atlas **8/9** 停服，用户须手动导出。这兑现了 7 月公布的下线时间表（前情见 08-04、08-06 归档"本周值得盯"）：OpenAI 把 agentic 浏览能力并入 ChatGPT 与 Codex，不再维护独立浏览器；官方给出的迁移路径是把 cookie 与密码导出到 ChatGPT 桌面应用、把书签导出到 Chrome。这款 2025 年 10 月发布的 macOS 优先浏览器存续不到 10 个月，期间始终未推出 Windows、iOS 与 Android 版本。产品形态的结论落在同一处：浏览器不是 agent 的必要载体，桌面应用加 Chrome 扩展的组合足以承接同样的任务。行动项：仍在 Atlas 内保留未导出书签或标签页的用户，数据已不可再从应用内取回，只能依赖此前的导出文件。
