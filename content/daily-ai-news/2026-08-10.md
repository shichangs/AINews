## 3. AI Agent 与开发者生态

### Claude Code 8/14 起把 auto mode 设为默认

依赖逐条批准做变更审计的团队须在 **8/14** 前显式改回原模式。Anthropic 的公告给出的依据是一项 **1,053** 名付费测试者参与的研究：auto mode 拦下 **89%** 的危险命令，人工审批的拦截率只有 **13.6%**，且在约 50 次提示后降至 **5%** 左右。已自设默认模式的用户会收到一次性切换询问。据 TechCrunch，第三方评测方 **Trajectory Labs** 对开启 auto mode 的 Fable 5、Opus 5、Sonnet 5 发起 **720** 次间接提示注入，无一成功。同时公布的是计费变化：分类器每次工具调用额外消耗的 token 对 Pro、Max、Team 三档用户不再收费。Enterprise、API 与 Bedrock、Google Cloud、Microsoft Foundry 渠道暂为可选。

## 4. AI 产品更新

### 📌 OpenAI Atlas 浏览器 8/9 停止工作

书签与浏览历史不自动迁移，未导出的数据 **8/9** 起已无法从应用内取回。这兑现了 7 月公布的下线时间表（前情见 08-04、08-06 归档"本周值得盯"）：OpenAI 把 agentic 浏览能力并入 **ChatGPT** 与 **Codex**，不再维护独立浏览器。官方给出的迁移路径是把 cookie 与密码导出到 ChatGPT 桌面应用、把书签导出到 Chrome。这款 2025 年 **10 月 21 日** 发布的 macOS 优先浏览器存续约 **9.6 个月**，期间始终未推出 Windows、iOS 与 Android 版本。行动项：仍依赖 Atlas 内书签的用户只能回到此前的导出文件，应用内已无补救路径。
