## 2. AI Agent 与开发者生态

### 🔥 xAI 发布 Grok Bot，捆绑在三档订阅内不单卖

企业客户只能排候补名单——Grok Bot 首发即绑死在 Cursor 订阅体系内。xAI 8/11 发布这款 beta 产品：每个 Bot 在云端拥有自己的一台电脑，用人类员工的方式登录邮箱、网站与内部系统完成多步任务，因而能覆盖无 API 或 MCP 集成的平台；用户合上笔记本后任务继续跑，Bot 只在需要审批时回来找人，还能通过"看一遍人怎么做"学会流程并存为例程，多个 Bot 之间互发消息、在群聊里分派工作。获取路径只有三条：**Cursor Ultra**（$200/月）、**Cursor Teams Premium**（$120/席/月）、**SuperGrok Heavy**（$300/月）。桌面与 iOS 已上线，Android 即将推出。Musk 称本周晚些时候随 Grok 4.6 扩大推送。

（来源：[xAI 官方公告](https://x.ai/news/introducing-grok-bot) · [Bloomberg](https://www.bloomberg.com/news/articles/2026-08-11/spacexai-unveils-grok-bot-to-work-like-a-team-of-ai-agents) · [VentureBeat](https://venturebeat.com/orchestration/spacexais-grok-bot-turns-agents-into-persistent-digital-coworkers-that-can-operate-your-apps-for-120-per-month)）

### NVIDIA 开源 Nemotron 3.5 Lightning 与模型路由库 NeMo Switchyard

NeMo Switchyard 把任务完成成本压到全程调用 Opus 4.8 的约 **1/3**。**Nemotron 3.5 Lightning** 是总参数 **300 亿**、活跃参数 **30 亿** 的 MoE 开源模型，8/11 随该路由库一同发布，定位是多 agent 系统里承担代码审查、工具调用、安全告警监控的高频专项层；对比同尺寸开源模型输出速度最高提升 **4 倍**，PinchBench 上完成万级任务比 Qwen3.6 35B 快 **30%**。上述 1/3 出自 NVIDIA 内部基准，合作方实测更具体：LangChain 在 145 个多轮任务中只把 **7%** 的调用给前沿模型，成本降 **74%**、准确率损失 **6%**；Ramp 成本降 **58%**；Cognition 接入 Devin Desktop 后降 **28%**。行动项：为 agent 栈做成本核算的团队可先跑一次自家任务集的路由基线。

（来源：[NVIDIA 官方博客](https://blogs.nvidia.com/blog/nemotron-lightning-switchyard-rtx-dgx/) · [NeMo Switchyard GitHub](https://github.com/NVIDIA-NeMo/Switchyard)）
