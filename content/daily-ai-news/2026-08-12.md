### 🔥 Gemini app 月活破 10 亿，Google 十亿级产品增至 14 个

## 2. AI Agent 与开发者生态

### 🔥 xAI 发布 Grok Bot，捆绑在 $120–$300 月费订阅内不单卖

想用 Grok Bot 必须先买 **Cursor Ultra**（$200/月）、**Cursor Premium Teams**（$120/席/月）或 SuperGrok Heavy 三者之一，企业客户只能排候补名单。xAI 8/11 发布这款 beta 产品：每个 Bot 在云端拥有自己的一台电脑，用人类员工的方式登录邮箱、网站与内部系统完成多步任务，因而能覆盖没有 API 或 MCP 集成的平台；用户合上笔记本后任务继续跑，Bot 只在需要审批时回来找人。Bot 可通过"看一遍人怎么做"学会流程并存为例程，多个 Bot 之间能互发消息、在群聊里分派工作。桌面端支持 macOS、Windows、Linux，iOS 已上线，Android 标注为即将推出。定价结构本身是策略：把 agent 塞进客户已经在付费的订阅里，比从零卖席位便宜，同时把 xAI 的 agent 路线与 Cursor 的商业体系绑在一起。Musk 称随 Grok 4.6 的更大范围推送在本周晚些时候到来。

（来源：[xAI 官方公告](https://x.ai/news/introducing-grok-bot) · [Bloomberg](https://www.bloomberg.com/news/articles/2026-08-11/spacexai-unveils-grok-bot-to-work-like-a-team-of-ai-agents) · [Unite.AI](https://www.unite.ai/xai-launches-grok-bot-always-on-ai-teammates-with-their-own-cloud-computers/)）

### NVIDIA 开源 Nemotron 3.5 Lightning 与模型路由库 NeMo Switchyard

按 NVIDIA 内部基准，NeMo Switchyard 把任务完成成本压到全程调用 Opus 4.8 的约 **1/3**。**Nemotron 3.5 Lightning** 是 **300 亿** 参数的 MoE 开源模型，8/11 随该路由库一同发布，定位是多 agent 系统里承担高频专项任务的那一层——代码审查、工具调用、安全告警监控——输出速度最高提升 **4 倍**、agent 任务完成时间缩短 **30%**。合作方给出的实测数字更具体：LangChain 在 145 个多轮 Deep Agents 任务中只把 **7%** 的调用路由到前沿模型，成本降 **74%**、准确率损失 **6%**；Ramp 在自建 SWE-Bench 上成本降 **58%**、运行时间降 **33%**；Cognition 把分级路由接入 Devin Desktop，平均成本降 **28%**。模型可在 RTX PC、DGX Spark、DGX Station 与 Jetson 上本地运行，NVIDIA 同时开源了用于后训练的 agentic 强化学习数据集。行动项：正在为 agent 栈做成本核算的团队，可用 Switchyard 的 GitHub 版本先跑一次自家任务集的路由基线。

（来源：[NVIDIA 官方博客](https://blogs.nvidia.com/blog/nemotron-lightning-switchyard-rtx-dgx/) · [NeMo Switchyard GitHub](https://github.com/NVIDIA-NeMo/Switchyard)）
