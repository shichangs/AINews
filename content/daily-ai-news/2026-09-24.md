## 2. 主要 AI Labs 动态

### Anthropic 称 Claude 发现类 CRISPR 酶系统 ART，已发预印本

ART 的功能仍未知，需经外部同行复现后才能判断其价值。**Anthropic** 9/23 发布称，约 **950** 个 Claude Agent 用 21 小时、消耗 2.1 亿 token，筛查逾 20 万个逆转录酶，标出约 3,500 个候选系统并就前 20 个撰写报告，最终发现主要存在于噬菌体中的"阵列相关逆转录酶"（**ART**）：由逆转录酶、一个伙伴基因和一段等距 DNA 重复阵列组成，结构上类似 CRISPR。

该逆转录酶此前已被研究报道过，Anthropic 称 Claude 首次注意到其伴随的重复阵列与附属蛋白；Amodei 承认斯坦福团队此前发现过"某些方面相似"的系统。实验室位于湾区、今年春季成立，只做 BSL-1/2 级研究，湿实验全部由人类科学家完成。CRISPR 先驱张锋评价该发现"值得进一步研究"。下一节点是 9/28 开赛的 Anthropic–Adaptyv 蛋白设计竞赛（详见 09-22 归档其他动态）。

### 📌 Meta Connect 为 Muse 加入实时语音与专属邮箱，改按交易抽成

Muse 将对"大量 token"免费，Meta 靠交易抽成盈利，与按订阅收费的 ChatGPT 路线不同。**Meta** 9/23 在 Connect 2026 主题演讲中为个人 Agent **Muse** 加入实时视频聊天、可定制声音的实时语音对话，并给每个用户的 Agent 分配专属邮箱；新增 Walmart、Best Buy、Gap、Sephora、Wayfair 等零售合作方，Amazon 仍未接入。Zuckerberg 称 Muse 将成为"数十亿人使用的个人超级智能"。

### Cursor 推出 Rollouts 与 Security Review，把 Agent 延伸到部署环节

Teams 与 Enterprise 客户获 10 天试用额度，分别约可监控 **50** 与 **500** 次变更。**Cursor** 9/23 上线两个机器人：**Rollouts** 为每个 PR 挂监控，在部署时按环境给出"健康 / 回归 / 无结论"判定，可开回滚 PR 但不会自动回滚；**Security Review** 在每个 PR 上报告可利用漏洞，覆盖注入、鉴权绕过、密钥泄露与 SSRF 等。

两项功能只对 Teams 与 Enterprise 计划开放。此前 Cursor 的 Bugbot 覆盖代码审查，此次把 Agent 职责从写代码、审代码推进到上线后的监控。下一检验点是约 10/3 试用额度到期后的计费方式。
