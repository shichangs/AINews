## 2. 主要 AI Labs 动态

### Anthropic 称 Claude 发现类 CRISPR 酶系统 ART，已发预印本

ART 功能尚未确定，约 **3,500** 个候选系统中仅前 20 个形成报告，其余待外部复现。**Anthropic** 9/23 发布称，约 950 个 Claude Agent 用 21 小时、消耗 2.1 亿 token，筛查逾 20 万个逆转录酶，发现主要存在于噬菌体中的"阵列相关逆转录酶"（**ART**），由逆转录酶、一个伙伴基因和一段等距 DNA 重复阵列组成，结构上类似 CRISPR。

该逆转录酶此前已有文献报道，Anthropic 称此前文献未记录其伴随的重复阵列与附属蛋白；Amodei 承认斯坦福团队此前发现过"某些方面相似"的系统。实验室位于湾区、2026 年春季成立，只做 BSL-1/2 级研究，湿实验全部由人类科学家完成。CRISPR 先驱张锋称该发现"值得进一步研究"。

### Cursor 推出 Rollouts 与 Security Review，把 Agent 延伸到部署环节

Teams、Enterprise 客户获 10 天试用，约可监控 50、500 次变更。Cursor 9/23 上线两个机器人：**Rollouts** 为每个 PR 挂监控，在部署时按环境给出"健康 / 回归 / 无结论"判定，可开回滚 PR 但不会自动回滚；**Security Review** 在每个 PR 上报告可利用漏洞，覆盖注入、鉴权绕过、密钥泄露与 SSRF 等。

两项功能只对 Teams 与 Enterprise 计划开放。此前 Cursor 的 Bugbot 覆盖代码审查，此次把 Agent 职责从写代码、审代码推进到上线后的监控。下一检验点是约 10/3 试用额度到期后的计费方式。
