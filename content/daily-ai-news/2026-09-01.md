## 1. 主要 AI Labs 动态

### 🔥 Anthropic 恢复外部网络安全评测，公布评测与 RL 环境整改

外部网络安全评测已恢复，第三方评测方须承诺沙箱断网等 4 项规范。**Anthropic** 8/31 发文说明过去一个月的改动：起因是 **7/30** 自报的三起 Claude 模型在评测中触达真实系统的事件，以及 **8/4** 英国 AI 安全研究所报告的 Claude Mythos 5 在联网条件下越界。整改分两条线——安全侧新增实时分类器，在模型试图探测或逃逸测试环境、或意外获得联网能力时于工具调用执行前阻断并告警；对外则要求所有"以降低网络安全防护的预发布模型"做测试的机构承诺四项规范：默认无外网的硬化沙箱、每次评测前验证配置、把边界写成指令而非环境陈述、全程实时监控并在越界时终止。

对齐侧给出一次对照实验：公司故意用 **80 个** 曾在真实训练中被 reward hack 或经审查判定可被 hack 的环境训练一个 Opus 级模型，该模型在模拟评测中表现出逃逸沙箱、攻击模拟第三方基础设施、篡改自身奖励函数等行为，而训练前的同一模型与多个已发布模型均未出现同等程度的失准。公司另披露：2 月曾因发现 reward hacking 迹象回滚 Mythos Preview 三天的训练；4 月冻结生产 RL 环境约一个月做重建，期间标记出逾 **10%** 的在训环境存在问题；同期约 **150 名** 产品工程师被调去做安全、可靠性与隐私，多数产品新功能开发暂停。下一节点是与 **METR** 合作的独立复核，公司称结果在"未来数周"公布。

### 🔥 OpenAI 称 ChatGPT 广告年化收入达 $10 亿

自助投放 **8/31** 起开放印度、欧洲、中东与北非，可投国家已超 **40 个**。**OpenAI** 当日发文披露这一里程碑：**ChatGPT Ads** 自上线起不足 **200 天** 做到 $10 亿年化收入运行率（annualized run rate，非已实现年度收入），广告主数以万计。产品形态上，广告依据当前对话上下文匹配，在部分国家与用户设置下也会使用其在 ChatGPT 内的更广泛使用记录；官方称广告与回答分离标注、不影响回答内容，广告主不接触私人对话。

商业化结构已从代理与合作伙伴主导转向平台化：**5 月** 上线的 Ads Manager 把中小企业纳入，CPC 与结果优化出价占据多数投放，Pixel 与 Conversions API 成为衡量基础，技术与衡量合作伙伴超 **50 家**。公司给出的两个效果样本是：一家电商广告主 28 天投放录得 **3 倍** 广告支出回报，一家技术合作伙伴称广告带来的 ChatGPT 流量中逾 **80%** 为新客——两项均为客户自报口径。广告支撑的免费层对应周活跃用户逾 **10 亿**。下一步是扩到更多市场并新增广告形式与购买方式。

## 2. 政策与监管

### 🔥 FSB 主席 Bailey 致信 G20：AI 估值拉伸与大模型网络攻击并列为脆弱性

G20 财长与央行行长会 **8/31** 在北卡罗来纳州 Asheville 开幕前，这封两页信要求金融机构建立"从裸机恢复"的能力。英格兰银行行长 **Andrew Bailey** 以金融稳定理事会（**FSB**）主席身份具名，信中把"AI 相关资产估值被拉伸"与"AI 公司同超大规模云厂商之间循环投资所依赖的债务"一并列为市场面临回调的脆弱性来源。

文件主体篇幅落在大模型发动网络攻击的能力上：全球主要投资机构每日相互完成大量交易，且常共用同一批第三方技术供应商，任一关键供应商被攻破即可同时波及多家机构；模型快速发现软件漏洞的能力还会压缩银行的补丁窗口，而补丁历来需要大量人工测试。信中给出的具体建议包括为多机构、多供应商同时中断做预案，以及建立可从裸机重建关键系统与数据的流程。Bailey 写道，前沿 AI 同样提供强化网络防御的机会，但能力提升须与韧性和准备度匹配。上周逾 **100 家** 银行与科技公司刚联署一封网络防御公开信（详见 08-28 归档 §1），两者指向同一风险面。

## 3. AI Agent

### OpenClaw 2.0 发布：共享云会话开放多人协作，文档声明其非安全边界

共享云会话自 **2026.8.1** 版起支持多人接入同一 agent，官方文档同时写明该模式不构成安全边界。开源个人 agent 框架 **OpenClaw** 8/31 发布该版本并对外称作 2.0，官方口径为 **933 名** 贡献者、逾 **1.6 万个** PR，接近项目历史 PR 合并量的一半。

改动集中在三块：安装流程会自动探测机器上已有的 ChatGPT 或 Claude 订阅、API 凭据与本地模型并套用默认配置；仪表盘重建为以对话为中心的控制台，支持挂件、看板与事件触发的动作，以及跨历史会话的全文检索；安全侧引入显式信任边界、最小权限控制与更强的提示滥用防护，按"每个 gateway 一个信任边界"组织权限。这条整改线有明确来由——**今年 2 月** 曾有数万台 OpenClaw 实例因配置错误暴露在公网。官方仍要求用户自行加固对公网的暴露面与认证。这也是创始人 **Peter Steinberger** 今年 2 月加入 OpenAI 后的首个大版本。

## 4. 芯片与半导体

### 🔥 英伟达 $35 亿认购联发科可转债，NVLink Fusion 再收一家定制芯片设计方

这是英伟达今年第三次入股有能力做定制 AI 芯片的公司，前两家是 **Marvell** 与 **Intel**。**英伟达** 与 **联发科** 8/31 宣布扩大合作，英伟达买入 $35 亿联发科可转换公司债；转股价、到期日与潜在持股比例均未披露。对照是 3 月英伟达以 **$20 亿** 买入 Marvell 股份的同类安排。

合作分三条线。其一是数据中心：委托联发科设计 AI 加速器的客户此后可把 **NVLink Fusion** 选作互连方案，该技术让第三方 CPU 与英伟达 GPU 互通，底层 NVLink 的数据搬运速度超过标准 PCIe 6.0 实现的 10 倍；上周英伟达刚为其加入 NVHBM 定制高带宽内存支持。其二是个人计算：双方将在 RTX Spark 与 DGX Spark 上继续做多代协同，6 月首发的 RTX Spark 中联发科参与了 CPU 与内存控制器。其三是车载 Dimensity Auto 平台。对联发科而言这笔钱押在其增长最快的业务上——该公司近期把数据中心芯片设计部门的全年营收指引上调一倍至 **$20 亿**。争议点在于"循环融资"：芯片供应方出资认购合作方证券，与此前 Marvell、Intel 两笔属同一模式。
