## 1. AI 算力与基础设施

### 🔥 OpenAI 签下 PORTS-Pike 约 8 GW-IT，英伟达向 SB Energy 投资 $15 亿

首批 **800 兆瓦** 定于 2028 年可用，六年建设期至 2032 年预计创造 **3.5 万个** 建设岗位、2,500 个长期运营岗位。8/17 三方同日公告：**OpenAI** 与 **SB Energy**、**英伟达** 及美国能源部达成协议，在俄亥俄州 Pike 县原朴茨茅斯气体扩散厂旧址开发 PORTS-Pike 技术园区，SB Energy 建设、持有并运营数据中心，按 20 年租约交付给 OpenAI，园区独家部署英伟达算力。英伟达向 SB Energy 投资 **$15 亿**，并为首期 4.25 IT-GW 的土地、电力与厂房建设提供信用支持，另持有追加 3.75 IT-GW 的选择权。SB Energy 与软银承诺新建至少 10GW 发电装机，并通过与 AEP Ohio 的机制投入至少 **$42 亿** 区域电网改造，声明电网升级成本不转嫁给俄亥俄州用户。社区侧，OpenAI 追加 $4,000 万社区基金（叠加 SB Energy 已承诺的 $4,000 万），并向约 **84.4 万** 名俄亥俄高校学生每人发放 $100 的 Codex 额度、总额至多 $8,400 万。这笔交易把 08-17 归档 📌 的传闻定了性：The Information 8/15 报道的"至多 $30 亿、其中约 $15 亿签约时投入"，落地为签约当期 $15 亿，其余部分未在公告中出现；同一报道所称英伟达为该项目担保约 **$1,000 亿** 信贷，官方公告未提及金额，仅表述为"信用支持"。

这笔表外承诺约为同期已报资本开支 **$6,000 亿** 的 5 倍，且是这些公司现有租约与长期借款合计的约 3 倍。《华尔街日报》梳理 Alphabet、亚马逊、微软、甲骨文、英伟达、博通、SpaceX、AMD 等 9 家公司的披露文件后给出该口径：约 **$1.2 万亿** 是尚未启用设施的租约，约 **$1.9 万亿** 是芯片、设备、能源及其他服务的采购承诺。个体上，Alphabet 披露的采购与合同义务为 **$8,110 亿**，三个月前为 $3,320 亿；Meta 披露的未来租赁义务为 $3,470 亿。这些承诺不计入传统资本开支口径，因此季度 capex 已经不足以衡量 AI 投入的真实规模——检验点落在利用率：下一批可对照的数据是英伟达 **8/26** 的 Q2 FY27 财报与各家 Q3 披露的义务余额，若义务增速继续快于收入增速，表外部分就会成为估值折价项。

## 4. AI 产品与开发者工具

### Cursor 上线 Origin 代码托管，PR 与 GitHub 双向同步

所有付费用户 8/17 起进入早期 Beta，企业组织管理员可选择退出。**Cursor** 的 **Origin** 提供仓库托管、pull request、代码浏览与 GitHub 同步：同步仓库实时更新，推送仍走 GitHub、后者保持为源头，评论在两侧秒级双向同步，GitHub 上分配给用户的 review 可以在 Cursor 内完成并合并。仓库内可直接向 agent 提问、改代码、更新 PR 或推分支。应用扩展已接入 Vercel（每个 PR 生成预览部署）、Depot 与 Buildkite（运行现有 GitHub Actions 工作流）。这一步把代码托管从 agent 的外部依赖变成自有环节——对团队的直接影响是权限与审计面从一个平台变成两个，评估时需要确认同步仓库的访问控制口径。

（来源：[Cursor Changelog](https://cursor.com/changelog/origin-code-hosting)）

### Claude Code v2.1.234：用量上限重置后自动续跑会话

用量上限重置后会话默认自动继续，不想要该行为的用户可在 `/config` 中关闭。8/17 发布的 **2.1.234** 版另加入三项：可选环境变量 `CLAUDE_CODE_PROJECT_DIR_NAME`（供为每个会话分配独立配置目录的宿主使用）、清除应用内文本选区的 `selection:clear` 快捷键动作，以及页脚与状态栏中显示 `MR !N` 及草稿／待处理／通过状态的 GitLab merge request 徽章。GitLab 徽章此前只有 GitHub 侧对应能力，这一项把非 GitHub 团队的状态可见性补齐。
